## VoxCPM2 generation scope

Nine voice stems are generated in total:

- K: 4
- 林雨晴: 1
- EVA: 2
- synthetic player-like voice: 2

The fixed-character subset is therefore 7 VoxCPM2 clone stems.

RAM policy on the Mac mini: after every 5 newly generated VoxCPM2 stems, unload the model, run Python GC and MPS cache cleanup, sleep 10 seconds, then reload only if more stems remain.

Generation/compositing script:

`asset_pipeline/generate_story_audio.py`

Working WAV stems are local-only under `asset_pipeline/work/` and are ignored by Git. Final MP3 assets are committed.

## Runtime playback contract

Clicking an audio bubble:

1. reveals the existing red transcript/design text;
2. plays the matching final MP3 when `data-audio-src` is present;
3. stops any previous story audio bubble before starting a new one;
4. normal chat bubbles remain silent.
