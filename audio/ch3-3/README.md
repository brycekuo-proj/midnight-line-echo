## Suggested five-round set

1. dog / dog / cat — answer: cat
2. cow / goat / cow — answer: goat
3. bird / bird / chicken — answer: chicken
4. cat / dog / cat — answer: dog
5. goat / chicken / chicken — answer: goat

UI should only expose three sound buttons (A/B/C or speaker icons), not animal names or animal icons.
